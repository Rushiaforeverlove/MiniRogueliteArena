# 深淵酒吧 · Abyss Bar

以 Unity 和 C# 製作的 2D Roguelite。從酒吧選擇角色、培養技能和管理造型，再前往地鐵站挑戰十波敵人。戰鬥中的四選一強化會隨角色、解鎖進度和本局已選卡片而變化。

## 開啟專案

1. 在 Unity Hub 加入此專案，以 Unity **6000.6.2f1** 開啟。
2. 開啟 `Assets/Scenes/MainMenu.unity` 後按 Play，即可依主選單、酒吧、戰鬥的順序遊玩。
3. 在 Unity 的 **Abyss Bar → Scene Preview** 選擇場景，可以在編輯模式查看。**Frame Current Scene** 將 Scene 視窗對準場景內容，**Show Camera Preview** 開啟 Game 視窗。

| 預設操作 | 功能 |
| --- | --- |
| WASD／方向鍵 | 移動 |
| 滑鼠左鍵 | 選角、選卡或戰鬥普攻 |
| E | 酒吧互動或戰鬥技能 |
| Q | 施放已解鎖的大招 |
| Shift | 戰鬥閃避 |
| 1–4 | 選擇局內升級卡 |
| Esc | 設定／返回 |

可從設定更改按鍵。想找場景、腳本或資料，請看[專案導覽](Docs/ProjectGuide.md)。想新增或調整卡片，請看[局內升級維護指南](Docs/RunUpgrades.md)。

## English

A 2D roguelite made with Unity and C#. Choose a character in the bar, train abilities and manage skins, then survive ten waves in the station arena. Leveling up offers a choice of four upgrades, with eligibility based on the selected character, unlocks, and current run.

Open the project with Unity **6000.6.2f1** and play `Assets/Scenes/MainMenu.unity`. For edit-mode previews, use **Abyss Bar → Scene Preview**. Movement defaults to WASD or the arrow keys, primary attack to left click, abilities to E and Q, and dodge to Shift. Press 1–4 to choose an offered upgrade.
