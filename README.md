# Mini Roguelite Arena

A small top-down 2D survival roguelite made with Unity and C#.

## Gameplay

Survive the arena for three minutes while enemies continuously spawn and chase the player. Defeat enemies with automatic attacks, collect experience gems, then choose one of three upgrades whenever you level up.

## Current Features

- Player movement with collision-based arena boundaries
- Camera follow system
- Enemies that spawn within the arena and chase the player
- Player health, enemy contact damage, and game-over state
- Automatic nearest-enemy attack with projectiles blocked by walls
- Enemy health and experience-gem drops
- Level progression with three upgrade choices: movement speed, attack speed, or maximum health
- HUD for health, level, experience, and elapsed time
- Victory and game-over result screen with restart

## Controls

| Input | Action |
| --- | --- |
| WASD / Arrow Keys | Move |
| 1 / 2 / 3 | Select a level-up upgrade |

## Tech Stack

- Unity 2D
- C#
- TextMeshPro UI
- Git and GitHub

## Project Goal

This project is being built as a focused portfolio piece to practice clean gameplay architecture, player feedback, and a complete game loop.

# 繁體中文

使用 Unity 與 C# 製作的小型俯視角 2D 生存 Roguelite 遊戲。

## 遊戲玩法

在競技場中存活三分鐘。敵人會持續生成並追擊玩家；利用自動攻擊擊敗敵人、收集經驗寶石，並在升級時從三種強化中做出選擇。

## 目前功能

- 玩家移動與競技場牆壁碰撞
- 攝影機跟隨系統
- 在競技場內生成並追擊玩家的敵人
- 玩家血量、敵人接觸傷害與遊戲結束狀態
- 自動鎖定最近敵人的攻擊，以及碰到牆壁會消失的子彈
- 敵人血量與經驗寶石掉落
- 三選一升級：移動速度、攻擊速度、最大生命值
- 顯示血量、等級、經驗與經過時間的 HUD
- 勝利／失敗結算畫面與重新開始功能

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| WASD / 方向鍵 | 移動 |
| 1 / 2 / 3 | 選擇升級 |

## 使用技術

- Unity 2D

- TextMeshPro UI
- Git 與 GitHub

## 專案目標

這是一個持續製作中的作品集專案，用來練習清楚的遊戲架構、玩家回饋與完整的遊戲循環。
