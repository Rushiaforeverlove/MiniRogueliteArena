# 深淵酒吧：局內升級系統 v1

這包是 v0.3 草案的第一版功能實作，尚未覆蓋你的 Unity 專案。先匯入、驗收，再調平衡與美術。

## 這次加入什麼

- 77 張卡：通用 15、道具 12、兩位角色各 15 張專屬、各 3 張節點五追加、各 7 張供其他角色使用的外援。
- 升級改成四選一；可點卡片，或按主鍵盤 1／2／3／4。
- 每格先抽品質，再抽分類，再抽卡；外援先均勻決定來源角色。四格不重複同一 ID。
- 品質權重暫為白 70／紫 25／金 5；分類暫為通用 30／道具 20／角色專屬 35／角色外援 15。
- 隱藏 Q 未解鎖、節點五未完成、其他角色未解鎖、已滿級等不符合條件的卡。
- 一次連升數級時，逐次四選一，不會漏掉後面的升級。
- E／Q／閃避增加充能格數、依序回充；免費 E 與真正扣充能的 E 分開計次。
- 屏障、回血、敵人減速／暈眩／失衡／偵察、道具區域、環繞造物，以及角色聯動效果。
- 傷害跳字、屏障數字、充能數字。
- 節點五可購買，永久加入該角色額外白／紫／金各一張；費用暫定 250 補給幣，可在角色資料修改。

新卡圖、酒瓶、衛星等先用測試圖形。卡片都有 Icon 欄位，之後可拖入自己的圖片。普通／重型武器仍讀原本子彈的顏色、圖片、速度與存活時間。

## 1. 匯入檔案

1. Unity 停止 Play Mode，先按 Ctrl+S 儲存場景。
2. 建議先將目前可玩的版本 commit，方便日後比較這次變更。
3. 解壓縮 `run-upgrades-v1-unity.zip` 到 Unity 專案以外的資料夾。
4. 把解壓後的 **Assets 資料夾內容**合併進：

   `C:\Users\blue7\MiniRogueliteArena\Assets`

5. 遇到同名 `.cs` 選擇取代。保留 Unity 專案原有的 `.meta`，不要先刪除原本腳本再重建，也不要把同一份腳本放到第二個路徑。
6. 回到 Unity 等待編譯。這次會新增 `Scripts/RunUpgrades`、`Scripts/Editor` 和 `Resources/RunUpgradeSeed.json`。

不要把 `Tests` 複製到 Unity 的 Assets。它包含隔離測試使用的引擎替身，放進 Assets 會造成重複型別。

本包沿用目前腳本名稱與既有序列化欄位，造型、補給幣、造型券、角色選擇和培養存檔不需清除。

## 2. 建立卡片資料

在 Unity 上方選單依序點：

**Abyss Bar → Run Upgrades → 1 - Prepare Data Assets**

它會建立：

- `Assets/Data/RunUpgrades/Cards`：77 個可在 Inspector 調整的卡片資產。
- `Assets/Resources/RunUpgradeDatabase.asset`：卡庫、角色名單、抽選權重。
- `Assets/Resources/CombatBalance.asset`：戰鬥數值倍率。

再次執行時會保留已存在卡片的調整與圖片，只補齊缺少的預設卡；也會保留卡庫的既有權重與角色設定。自己新增的卡片記得放進資料庫 Cards 陣列。

選取 RunUpgradeDatabase，確認：

- Cards 有 77 張。
- Roster 有偵察員與防衛隊員的 CharacterData。
- 目前兩位都可選，所以兩位的 Unlocked By Default 都勾選。未來加入鎖定角色時，再由角色解鎖功能更新名單狀態。

## 3. 安裝到戰鬥場景

1. 在 Project 開啟 **Main** 戰鬥場景。
2. 點 **Abyss Bar → Run Upgrades → 2 - Install In Open Main Scene**。
3. 工具會在 Player 加入本局升級元件，建立四選一介面，並設定 UpgradeManager 的參考。
4. Hierarchy 選 UpgradeManager，確認 **Chinese Font** 是之前已能顯示中文的 Noto／CJK TMP Font Asset。如果不是，手動拖入那個字型資產。
5. Canvas 下會新增 **Run Upgrade Choices**。遊戲開始時它會隱藏，升級時才顯示。
6. 按 Ctrl+S 儲存 Main。

原本三選一面板會被隱藏，不必繼續設定舊的三個按鈕。新卡片按鈕由程式綁定。確認新版正常後，可以自行刪除舊面板。

最後執行 **3 - Validate Database**。Console 應顯示 77 張卡驗證成功。

## 4. 數值倍率：不要再手動把原始值乘一次

目前原有 CharacterData／Projectile／敵人 Prefab／技能資產依然保存小數值，由 CombatBalance 統一換算一次。

| 項目 | 資產中的原始值 | 遊戲內基準 |
|---|---:|---:|
| 偵察員基礎生命 | 5 | 1,000 |
| 防衛隊員基礎生命 | 8 | 1,600 |
| 普通子彈傷害 | 1 | 100 |
| 重型子彈傷害 | 3 | 300 |
| 普通敵人生命 | 3 | 300 |
| 敵人接觸傷害 | 1 | 100 |
| 原培養 HP +1／傷害 +1 | 1 | +100 |

若你已完成培養，開局生命還會加上已購買的 HP，例如偵察員完成兩段 HP 培養會是 1,200。

**新升級卡 Numbers 已使用遊戲內單位**：續杯生命 +100，就是 +100；不用再乘倍率。百分比、冷卻、距離、經驗與貨幣不放大。

傷害運算使用浮點數，避免 10% 增傷因整數截斷失效。跳字顯示計算後傷害；吸血累積只計敵人實際扣掉的生命，排除溢傷。

## 5. 先驗收這五件事

1. 從酒吧出戰，角色、造型、E／Q 與原本的牆壁碰撞仍正確。
2. 比對開局 HP、普通攻擊跳字與敵人擊殺次數。
3. 升級出現四張不同卡；畫面暫停，點選或按 1～4 後恢復；多級經驗會接續選卡。
4. 取得同一張可重複卡，顯示 Lv.1 → Lv.2；唯一卡與滿級卡不再出現。
5. 戰鬥結束回酒吧再出戰，本局卡片效果歸零，永久培養、貨幣和造型仍保留。

這五項通過後，再驗收各流派，不必一開始就靠隨機抽完 77 張。

## 6. 用測試視窗指定卡片

點 **Abyss Bar → Run Upgrades → 4 - Battle Test Window**，接著在 Main 進入 Play Mode。

- 下拉選擇卡片，按「套用所選卡片一級」。
- 「忽略選角／Q／節點門檻」只用於本局測試，可測未完成節點五的追加卡，正式抽選仍遵守門檻。
- 「本局預覽 Q」讓本局可測 Q，不修改永久解鎖存檔。
- 「打開一次四選一」可以檢查介面與選卡流程。
- 停止 Play Mode 後測試效果清除；測試視窗不會扣貨幣或寫入永久培養。

建議依序測：

| 測試組合 | 應看到的行為 |
|---|---|
| 環身酒刃 ×3 | 數量依序 1、2、3 枚，不是累加到 6 枚；接觸傷害有冷卻；隔牆不傷敵 |
| 公轉酒櫃＋環身酒刃 | 三瓶酒各有燃燒、減速、屏障；閃避後兩種造物都加速 |
| 備用彈匣＋緊急滑步 | E／閃避各多一格，先後消耗、依序回充 |
| 偵察員：先遣記錄＋交叉校射 | 偵察標記與 E 側射聯動；側射不會無限生側射 |
| 偵察員：移動射界＋零號航線 | 一條火線共用，子彈增傷不重複疊；站在線上可追加導引彈 |
| 防衛隊員：反撞條款 | 敵人打空屏障才反擊；屏障自然到期不反擊 |
| 防衛隊員：回聲地板＋三重震爆 | 第一震留回聲區，後續直接震盪可提前引爆；追加傷害不再連鎖 |
| 防衛隊員：終場重拍 | Q 最後一震後 0.35 秒追加聚怪終震，傷害依原 Q 總基礎傷害計算 |
| 血色回甘 | 累積 2,000 實際直接傷害回復 100；道具與溢傷不計 |
| 最後一杯 | 同一局只擋一次致命傷害；重新開局才重置 |

也請測試貼牆閃避、子彈撞牆、敵人多碰撞器、開選卡時的技能暫停、死亡時尚未打完的三重震波，以及 Windows 建置。這些需要真正的 Unity 場景驗收。

## 7. 節點五與滿培獎勵

角色資料新增：

- **Node Five Cost**：預設 250 補給幣。
- **Mastery Reward Skin**：該角色的滿培獎勵造型。

節點四完成後，節點五才可買。購買後依 CharacterId 存檔，該角色的三張追加卡會在下一局加入卡池；重複按按鈕不重複扣款。

如果已決定獎勵造型：先建立 CharacterSkinData，把它放進該角色的 Skins，再拖進 Mastery Reward Skin。滿培購買時會一次性解鎖，不會自動換裝。

因為正式獎勵美術還沒決定，這個欄位可先留空。完成紀錄會保留為待發獎依據；之後設定有效造型，再開啟培養面板或出戰時會補發一次。已發過獎勵後不會因為更換欄位再發另一套。

## 8. 之後如何調整與擴充

### 調整現有卡

打開 `Assets/Data/RunUpgrades/Cards`，選卡片直接改 Inspector：名稱、說明、圖片、品質、分類、Max Rank、Draw Weight、門檻和 Numbers。

- Max Rank = 0 表示不限次數；1 表示只能選一次。
- Draw Weight = 0 可以暫時從抽選停用這張卡。
- Numbers 中單一值通常是固定參數，陣列是各等級的數值表。`healthPerRank` 等 PerRank 參數表示每次取得的增量；`counts` 等等級表表示目前總效果，例如酒刃 1／2／3 枚。
- 改數值時也要改 Description；這版不會自動從 Numbers 產生中文敘述。
- 調整卡片後執行 Validate Database，再用測試視窗測一遍。

### 新增同類效果的卡

1. Create → Abyss Bar → Upgrades → Card。
2. 給新的穩定 ID，填入分類、品質、門檻、說明、Icon。
3. 使用現有 Effect Key，填入同一模板所需的 Numbers。
4. 將新資產加入 RunUpgradeDatabase 的 Cards。
5. 驗證卡庫與測試。若兩個同模板版本要同局共存，需另外確認疊加與聯動規則。

例如另一張加生命卡，可以沿用 `stat.max_health`，設定 `healthPerRank = 150`、`healPerRank = 150`、Max Rank = 3，不需改 UpgradeManager。

### 新增全新機制

新增一個繼承 `RunEffect` 的類別，實作需要的事件，再在 `UpgradeEffectRegistry` 註冊新的 Effect Key 與參數名稱。卡片與介面不需要跟著重寫。詳細範例見「擴充與維護.md」。

### 新增角色

角色使用新的 CharacterId，加入資料庫 Roster；專屬與外援卡填該 ID。抽選規則不會把當前角色自己的外援抽給自己。角色購買／解鎖功能可更新資料庫查詢使用的解鎖狀態，不必將所有外援規則重寫。

## 9. 已做與仍需做的驗證

已使用本機 Unity 6000.6.2f1 的組件編譯遊戲碼及 Editor 工具，並執行隔離邏輯檢查：抽選、角色門檻、等級上限、充能、傷害／屏障事件、多段技能、環繞與節點五存檔；包含全部 77 個效果的基本事件流程。

隔離測試的物理、視覺、引擎生命週期與 PlayerPrefs 都使用替身，不等同實際 Unity Play Mode、畫面驗收或 Windows 執行檔測試。原生批次 Unity 啟動未產生可用驗證結果。驗收紀錄見「驗證紀錄.md」。

這版供功能測試與後續調整；正式 Steam 版本還需依實際場景做效能分析與平衡。本版跳字有物件池，子彈、道具和特效的產生入口已集中，之後可在入口加入物件池，卡片效果不必逐張修改。
